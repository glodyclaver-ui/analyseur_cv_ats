========================================================================
GUIDE D'INSTALLATION ET DE LANCEMENT EN LOCAL
Projet : ATSMatcher Pro (Analyseur de CV & Offres d'Emploi)
Auteur : Glodi-Placide Oleko Diomba
========================================================================

1. PRÉREQUIS (À FAIRE UNE SEULE FOIS SUR L'ORDINATEUR)
------------------------------------------------------------------------
- Avoir Python 3 installé sur votre ordinateur (téléchargeable sur python.org).
- Lors de l'installation de Python sur Windows, veillez à bien cocher 
  la case "Add python.exe to PATH".


2. INSTALLATION DES BIBLIOTHÈQUES REQUISES
------------------------------------------------------------------------
Ouvrez un terminal (ou le terminal intégré de VS Code) directement dans 
le dossier principal du projet, puis exécutez la commande suivante :

    python -m pip install -r requirements.txt

(Note : Cette commande télécharge et installe automatiquement les 
modules nécessaires : Flask, pypdf, requests, beautifulsoup4, reportlab. 
Une connexion Internet est requise uniquement pour cette étape).


3. LANCEMENT DE L'APPLICATION
------------------------------------------------------------------------
Dans le même terminal, tapez la commande suivante et appuyez sur Entrée :

    python app.py

Le serveur local va démarrer et afficher l'adresse :
    http://127.0.0.1:5002


4. UTILISATION DANS LE NAVIGATEUR
------------------------------------------------------------------------
- Ouvrez votre navigateur web (Chrome, Edge, Firefox).
- Tapez l'adresse : http://127.0.0.1:5002
- L'application fonctionne désormais 100 % en local sur votre machine 
  (aucun fichier CV n'est envoyé vers un serveur externe).
- Pour arrêter l'application, retournez dans le terminal et appuyez 
  sur les touches : Ctrl + C.
